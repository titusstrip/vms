# Claude Code Project Guide

## Objectif

Ce dépôt est prêt à être utilisé avec Claude Code. Les fichiers et dossiers doivent rester lisibles, modulaires et bien documentés.

## Règles de travail

- Écrire un code propre et maintenable.
- Préférer des composants réutilisables et des fonctions claires.
- Documenter les changements importants dans le README ou dans `docs/`.
- Ajouter des tests pour les fonctionnalités critiques.

## Conventions

- Utiliser des noms explicites pour les modules.
- Séparer logique métier, interfaces et configuration.
- Garder les variables d’environnement dans un fichier `.env.example` ou dans `config/`.

## Workflow recommandé

1. Comprendre le besoin métier.
2. Créer ou modifier les composants concernés.
3. Vérifier les tests et la cohérence.
4. Mettre à jour la documentation si nécessaire.
